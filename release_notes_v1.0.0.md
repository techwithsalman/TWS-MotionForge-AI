## 🚀 Welcome to TWS MotionForge AI

**TWS MotionForge AI** is a professional, 100% free, fully local AI video production studio designed for creators, educators, and storytellers. Turn topics and scripts into animated videos with voiceovers, synchronized subtitles, background music, and sound effects—all running locally on your PC without cloud subscriptions or API keys.

## 🛠️ Installation Instructions

1. **Download:** Download `TWS-MotionForge-AI-Setup-1.0.0.exe` from the Assets section below.
2. **Run Installer:** Double-click the setup file. No administrative privileges are required.
3. **Choose Directory:** By default, the application installs to `%LOCALAPPDATA%\Programs\TWS MotionForge AI`.
4. **Launch:** Use the **TWS MotionForge AI** Desktop shortcut or find it in your Start Menu.
5. **Completely Offline:** Disconnect from the internet anytime—all text-to-speech, transcription, animation engines, and rendering run 100% locally on your machine.

## ✨ Key Features

- **Dual Local Voice Studio:**
  - High-fidelity Kokoro Neural TTS (`af_bella`, `af_sarah`, `am_adam`, `am_michael`, `bf_emma`, `bm_george`).
  - Zero-latency Windows SAPI5 native speech synthesis fallback.
- **Word-Level Subtitle Synchronization:** Powered by bundled Faster-Whisper (`small.en`) for precise caption timing.
- **B1–B7 Animation Directing Engine:**
  - **B1:** Classic Stickman Animation (16:9 Landscape).
  - **B4:** Hook & Cutout (9:16 Portrait Shorts/Reels/TikTok).
  - **B6:** Puppet Master Multi-Plane Parallax (16:9 Landscape).
  - **B2, B3, B5, B7:** Educational, kinetic typography, causal interruption, and fast-forward documentary styles.
- **Curated Audio Library:** 890 royalty-free background music tracks and sound effects categorized by mood.
- **Local Project Persistence:** User projects and renders are safely stored in your user profile documents directory and are preserved across updates and uninstallation.
- **Privacy & Security First:** Zero data leaves your computer. No telemetry, no cloud keys, context-isolated Electron architecture.
